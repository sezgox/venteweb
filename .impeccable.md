# Design context — Vente (monorepo)

Project-level hints for Impeccable / design skills. Refine with `/impeccable teach` in your agent when you want a deeper brief.

## Target audience

- People discovering and joining local events (social, sports, culture) on their phone first.
- Primary delivery: **Android MVP**; iOS planned after. Expect touch-first density and clear hierarchy under sunlight and on the go.

## Use cases

- Browse and search events (list + map).
- Create and manage events; lightweight social/profile flows.
- Auth and maps integrated; offline-tolerant UX where possible.

## Brand personality / tone

- **Energetic but trustworthy**: community and real-world gatherings, not generic SaaS.
- **Mobile-native restraint**: confident accent (brand red on key actions) without loud “marketing” motion; prefer subtle elevation and readable type over decorative gradients in chrome.
- **Clarity over novelty**: obvious navigation, legible labels, sufficient contrast; avoid purple-gradient “AI default” aesthetics.

## Constraints

- **Ionic + Angular** (`vente-mobile`): use Ionic theming (`--ion-*`), safe areas, Capacitor-friendly patterns.
- Align UX and contracts with **ventewebf** where features overlap; mobile layout need not match web pixel-for-pixel.
